# Дочки-сыночки

Сайт частного детского сада в Актау. Русский и казахский языки.

Просмотр: https://babazazu-game.github.io/dochki-synochki-aktau/

Статические HTML, CSS и JavaScript. GitHub Pages автоматически публикует изменения ветки main из корня репозитория. После каждой согласованной правки обновляем локальные файлы, публикуем ту же версию в main и проверяем клиентскую ссылку после сборки.

На постоянный хостинг переносится содержимое этой же версии: index.html, style.css, app.js, content-data.js, gallery-data.js и assets/. Серверная программа и база данных не нужны.

Расписания и правила оформлены прямо на сайте. Исходные документы хранятся отдельно от публикуемых файлов.
